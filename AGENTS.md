## Agent skills

### Issue tracker

GitHub Issues (via `gh` CLI) on `QzKING2023/Qz-FTG-Wiki`. External PRs are a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

All five canonical labels use their default strings: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
